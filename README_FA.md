# NovaPay Android — Kotlin + Jetpack Compose

پروژهٔ اندروید بر اساس شیت UI ارسالی ساخته شده است. زبان پیاده‌سازی Kotlin و رابط کاربری Jetpack Compose است.

## طراحی

- تم تیره با پس‌زمینهٔ سرمه‌ای/ذغالی
- رنگ تأکیدی زرد/طلایی
- کارت‌های گوشه‌گرد، دکمه‌های تمام‌عرض، فرم‌ها و ردیف‌های اطلاعاتی مشترک
- چیدمان راست‌به‌چپ و متن‌های فارسی
- ناوبری پایین برای خانه، کیف پول، تراکنش‌ها و پروفایل

## صفحه‌ها و جریان‌ها

- شروع، ورود، ثبت‌نام و بازیابی رمز
- خانه، موجودی و نمای کلی هزینه‌ها
- کیف پول، حساب‌ها و کارت‌های بانکی
- انتقال وجه، انتخاب مخاطب، افزایش موجودی و برداشت
- پرداخت، اسکن QR نمایشی و کد QR شخصی
- قبوض و خدمات، جزئیات و پرداخت قبض
- فهرست تراکنش‌ها، فیلتر و جست‌وجو، جزئیات و رسید
- اعلان‌ها، مخاطبین و جزئیات مخاطب
- پروفایل، تنظیمات، امنیت، پشتیبانی و گفت‌وگوی پشتیبانی
- گزارش حساب و دسته‌بندی هزینه‌ها

## اجرای پروژه

1. پروژه را در Android Studio باز کنید.
2. اجازه دهید Gradle Sync انجام شود.
3. یک شبیه‌ساز یا گوشی با Android 7.0 (API 24) یا بالاتر انتخاب کنید.
4. پیکربندی `app` را اجرا کنید.

نیازمندی‌های پروژه: JDK 17، Android Gradle Plugin 8.8.2، Kotlin 2.0.21 و Android SDK 35.

## نکته‌های مهم نسخهٔ فعلی

- این نسخه یک نمونهٔ UI تعاملی و قابل اجرا با داده‌های نمونه است؛ به سرویس بانکی، احراز هویت واقعی یا API پرداخت متصل نیست.
- بخش دوربین/اسکنر QR فعلاً نمایشی است و هنوز مجوز دوربین و پردازش تصویر به آن متصل نشده است.
- QR شخصی با الگوی نمایشی رسم می‌شود و کد پرداخت واقعی نیست.
- اشتراک‌گذاری رسید، خروجی گزارش و بعضی گزینه‌های مدیریتی فعلاً نقطهٔ اتصال UI دارند و برای نسخهٔ عملیاتی باید به Android Sharesheet، ذخیره‌سازی فایل یا Backend متصل شوند.
- تصویر مرجع با عرض ۱۶۰ پیکسل ارائه شده بود و نوشته‌های بسیاری از کارت‌ها قابل خواندن نبودند؛ به همین دلیل ساختار ظاهری و خانوادهٔ صفحه‌های قابل تشخیص بازسازی شده‌اند، نه نام و متن دقیق تک‌تک فریم‌های ریز تصویر.

## ساختار اصلی

```text
NovaPayAndroid/
├── app/
│   ├── build.gradle.kts
│   └── src/main/
│       ├── AndroidManifest.xml
│       ├── java/com/example/novapay/MainActivity.kt
│       └── res/values/strings.xml
├── build.gradle.kts
├── settings.gradle.kts
└── gradle.properties
```

## ساخت APK با GitHub Actions

در مسیر `.github/workflows/build-apk.yml` گردش‌کار ساخت خودکار APK قرار دارد. پس از Push به شاخهٔ `main` یا `master`، GitHub برنامه را Build می‌کند و Artifact قابل دانلود `NovaPay-debug-apk` را در صفحهٔ اجرای Workflow قرار می‌دهد. راهنمای کامل در فایل `GITHUB_BUILD_FA.md` است.
